# BDM Performance

Landing page estática para captação de interessados em se tornar um autorizado BDM Performance. Não requer build: publique o conteúdo da raiz em GitHub Pages.

O formulário abre o WhatsApp comercial informado no briefing. A atribuição de campanha é persistida apenas na sessão e os eventos de `dataLayer` nunca recebem nome ou telefone.
