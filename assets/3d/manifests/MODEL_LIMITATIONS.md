# Limitações do modelo — BDM Mechanical Reveal

- Geometria Sketchfab é V8 genérico estilizado (~2.1M faces), não CAD de motor BDM real.
- Materiais originais do GLB eram inadequados (clay); foram substituídos por shaders PBR próprios.
- Exploded view completo não foi produzido nesta entrega.
- Masters 7680px não foram re-renderizados nativamente; o maior still de produção usado no hero web é 2560/1920 (otimizado WebP).
- Vídeo hero 16:9; feed/story gerados a partir das câmeras dedicadas.
